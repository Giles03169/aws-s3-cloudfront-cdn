# 🌍 AWS S3 + CloudFront Static Site with CDN

This project shows how to speed up and secure a static website hosted on S3 using Amazon CloudFront CDN.

## 🔧 Tech Stack
- AWS S3 (static site)
- AWS CloudFront (CDN + HTTPS)
- HTML/CSS
